# Criliant

Platform simulasi ujian, kuis mikro, dan arena interaktif dengan arsitektur Public Read & Authenticated Write, gamifikasi Karma & Gelar, serta anti-bot report defense.

## Tech Stack
- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Lucide React & Canvas Confetti

## Getting Started
```bash
npm install
npm run dev
```

Buka [http://localhost:3001](http://localhost:3001) di browser.
